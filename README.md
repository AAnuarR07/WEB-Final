# Our Favorite Games — Final Project

## Pages
- `index.html` — BeamNG.drive
- `minecraft.html` — Minecraft
- `cyberpunk.html` — Cyberpunk 2077
- `gta5.html` — GTA V
- `rdr2.html` — Red Dead Redemption 2
- `cs2.html` — Counter-Strike 2

All six pages use the same layout and functionality. To add pages five and six, duplicate a page and change its title, logo, main image, description, bullet list and sidebar images. Add the new game to the `games` array in `js/script.js` so it appears in search

## Implemented features
- Responsive CSS Grid/Flexbox layout
- Shared light/dark mode preference using localStorage
- Sign Up / Log In simulation and Profile Page section (`#profile`)
- Custom email, phone, password and required-field validation
- Live game search/filter with last query saved in localStorage
- CheapShark public API integration for current PC game deals, including loading and error states
- Hover transitions and animated buttons

## Run
Open `index.html` in a browser. The API needs an internet connection. For best results, use a local web server or host on GitHub Pages
